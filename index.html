Forgetting without Erasure: Editable Memory for Interactive Video Generation

Yilin Liu1, Feng Cheng2, Angtian Wang3, Chongyang Ma3, Pew-Thian Yap1, Jian Wang4, Miles Chen4
1UNC-Chapel Hill 2ByteDance Seed 3ByteDance Intelligence Creation 4TikTok Inc.

Abstract

Real-time interactive video generation requires rapidly adapting to changing user prompts while preserving long-range consistency. KV caching enables streaming efficiency and provides long-term memory, but also creates semantic inertia that resists transitions during prompt switches and causes stale semantic leakage. We address this dilemma by recasting prompt switching as a dynamic cache-editing problem. Rather than resetting the cache or heuristically blending old and new context, our method removes only the stale semantic components, allows the new prompt to take full effect while preserving the historical content relevant to the new scene.
